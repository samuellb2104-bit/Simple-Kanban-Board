# Drag and Drop API

Proyecto simple en HTML, CSS y JavaScript para aprender a utilizar la **Drag and Drop API**.

Permite arrastrar elementos y soltarlos dentro de una zona de destino.

## Conceptos principales

* `draggable`: permite que un elemento pueda ser arrastrado.
* `dragstart`: se ejecuta cuando comienza el arrastre.
* `dragover`: se ejecuta cuando el elemento pasa sobre la zona de destino.
* `drop`: se ejecuta cuando el elemento es soltado.
* `dataTransfer`: permite guardar y obtener información del elemento arrastrado.

## Tecnologías

* HTML
* CSS
* JavaScript
